# Python Experiments

A collection of applied AI/ML and statistics experiments, organized by subject into self-contained folders, each with its own README explaining the project, how it works, and how to run it.

## Projects

| Folder | Topic | Projects |
|---|---|---|
| [`ab-testing/`](ab-testing) | A/B Testing & Experimentation | Significance over time (video), segmented conditions, 50/50 convergence |
| [`knowledge-distillation/`](knowledge-distillation) | Teacher-Student Model Distillation | Professor/student distillation pipeline, BERT-tokenized variant, schema diagram |
| [`llm-finetuning/`](llm-finetuning) | LLM Fine-Tuning | DeepSeek-R1 LoRA/QLoRA fine-tuning on a medical reasoning dataset |
| [`sampling-statistics/`](sampling-statistics) | Statistical Inference | Central Limit Theorem demo on real EPA air quality data |
| [`recommender-systems/`](recommender-systems) | Recommender Systems | Content-based music recommender simulation |

Each folder's README explains the purpose, methodology, and requirements for every script inside it.
